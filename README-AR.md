# MMY.YE — نسخة ويندوز وأندرويد

مشروع واحد يُنتج: **برنامج ويندوز (.exe)** و**تطبيق أندرويد (.apk)** من نفس ملف النظام `src/index.html`.
ملف النظام الأصلي لم يُعدَّل؛ كل التعديلات تُطبَّق تلقائياً عند البناء (خطوط محلية، تصحيح CSP، طبقة توافق).

## الطريقة الأسهل: البناء التلقائي على GitHub (بدون تثبيت شيء على جهازك)
1. أنشئ مستودعاً خاصاً على GitHub وارفع محتوى هذا المجلد.
2. من تبويب **Actions** شغّل **Build Windows & Android**.
3. بعد دقائق نزّل `windows-installer` (ملف التثبيت) و`android-apk` من قسم Artifacts.

## البناء على جهازك
المتطلبات: Node.js 20+ ، ولأندرويد أيضاً Android Studio (يتضمن JDK وSDK).

```
npm install
npm run dev            # تجربة نسخة ويندوز مباشرة
npm run win            # ينتج dist/*.exe (مثبّت + نسخة محمولة)

npm run android:add    # مرة واحدة فقط
npm run android:prepare # يضيف صلاحية البصمة لأندرويد
npm run icons          # أيقونات أندرويد من مجلد assets
npm run android:open   # يفتح Android Studio ← Build > Build APK(s)
```

## لتحديث النظام لاحقاً
استبدل `src/index.html` بالنسخة الجديدة ثم أعد البناء. بيانات المستخدمين تبقى محفوظة على الجهاز.


## التعديلات المضافة على النظام (الإصدار 1.1)
- **الافتتاح على «نظرة عامة»:** يفتح البرنامج دائماً على نظرة عامة بعد الدخول وعند إعادة التشغيل. كان السابق ينقل المستخدم إلى الإعدادات عند الدخول بكلمة المرور الافتراضية؛ استُبدل ذلك بشريط تنبيه أحمر في أعلى الصفحة يحمل زر «تغيير كلمة المرور» دون إجبار على تغيير القسم.
- **لوحة التحكم (قسم جديد):** ملخص للنظام، إعداد جاهزية القسم المركزي، إجراءات سريعة (نسخ احتياطي، استيراد، المظهر، القفل، إعادة ترتيب الأقسام)، وحالة التخزين.
- **لوحة عرض الصور (قسم جديد):** صور الواجهة وصور الكادر وإدارة الإعلام وبطاقات التعريف، مع تصفية وبحث بالاسم وعرض مكبّر.
- **جاهزية القسم المركزي:** تُحسب الأدوات على **16 شخصاً** (قابل للتعديل). المطلوب لكل أداة = عدد الأشخاص × الوحدات لكل شخص (الافتراضي 1)، والجاهز = الكميات بحالة «متاح» فقط. النسبة = مجموع المغطّى ÷ مجموع المطلوب. تظهر في إدارة الإعلام ولوحة التحكم ونظرة عامة، وتُحفظ ضمن النسخة الاحتياطية.

## ملاحظات مهمة
- **البيانات** تُحفَظ محلياً على كل جهاز (localStorage + IndexedDB) كما في النسخة الأصلية؛ لا مزامنة بين الأجهزة. استخدموا «تصدير نسخة احتياطية» دورياً. على أندرويد يفتح التصدير قائمة «مشاركة/حفظ».
- **الدخول بالبصمة:** على أندرويد يستخدم التطبيق واجهة البصمة الأصلية عبر `@capgo/capacitor-native-biometric` (Capacitor 6). من الإعدادات اختر «تسجيل هذا الجهاز»، ثم يظهر زر «الدخول بالبصمة» في شاشة القفل. إذا لم تتوفر البصمة يبقى الدخول بكلمة المرور متاحاً.
- **توقيع APK**: الناتج `debug` مناسب للتجربة والتوزيع الداخلي. للنشر في Google Play أنشئ مفتاح توقيع وابنِ `bundleRelease`.
- **ويندوز SmartScreen**: قد يحذّر من ملف غير موقَّع؛ يزول ذلك بشهادة توقيع كود.
- نسخة الويب المعدّلة تحتاج بيانات نسخة المتصفح القديمة: صدّرها من النسخة القديمة واستورِدها في التطبيق.
